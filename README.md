# 🏨 Hotel Reservation Analysis Dashboard (Power BI)
## 📊 Project Overview
 An interactive Power BI dashboard analyzing hotel reservation data to track bookings, revenue, cancellations, and customer segments for data-driven decision-making.
# 🎯 Objectives
* Analyze hotel reservation trends across different market segments

* Track revenue performance and booking behavior

* Understand the impact of seasonality, lead time, and cancellations

* Identify high-value customer segments and room types

# 🔑 Key Metrics (KPIs)
* Total Adults: 67K

* Total Reservations: 36K

* Total Week Nights Booked: 80K

Total Revenue: 15.99M
# 📈 Dashboard Insights
 ## ✔️Season Analysis:
  Comparison between high season and low season revenue and pricing trends.

 ## ✔️Market Segment Performance:
   Revenue contribution from Online, Offline, Corporate, Aviation, and Complimentary bookings.

## ✔️Lead Time Analysis:
  Lead time distribution by market segment and room type.

 ## ✔️Room Type Analysis:
  Maximum adults and repeat bookings by reserved room type.

 ## ✔️Booking Status Impact:
  Comparison of average room price and lead time between Cancelled and Not Cancelled bookings.

## ✔️Revenue Distribution:
  Visual breakdown of total revenue by market segment.

# 🛠 Tools & Technologies
* Power BI – Data visualization & dashboard creation

* Excel / CSV Dataset – Data source

* DAX – Calculated measures & KPIs

* Data Cleaning & Transformation – Power Query
# 📌 Business Value
* This dashboard can help:

* Improve revenue management strategies

* Reduce cancellation impact

* Optimize pricing and room allocation

* Identify profitable customer segments
# 🚀 How to Use
** Download the .pbix file from this repository

** Open it in Power BI Desktop

** Interact with filters (Month, Season, Market Segment) to explore insights
